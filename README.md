My First Particle System 🌈🔥

A simple interactive particle system that creates a colorful, fire-like visual effect using mouse input.

About the Project

This project is an introduction to particle systems, demonstrating how particles can be generated, animated, and displayed in response to user interaction.

When the mouse button is held down, particles spawn from the mouse cursor and fall downward, creating a vibrant rainbow-colored fire effect.

Features
Interactive particle generation: Particles spawn while the mouse button is held down.
Mouse-based controls: Particle emission follows the mouse cursor.
Rainbow colors: Particles create a colorful visual effect.
Falling animation: Particles move downward after being generated.
Real-time interaction: The effect responds dynamically to user input.

Getting Started
Prerequisites
Visual Studio
A compatible Windows development environment
The required project dependencies and development tools
Installation
Clone the repository:
bash
git clone https://github.com/Gudeyori/MyFirstParticleSystem.git

Navigate to the project directory:
bash
cd MyFirstParticleSystem

Open the solution file in Visual Studio:

VGP230_Week1a.slnx

Build and run the project.
How to Use
Launch the application.
Move your mouse around the application window.
Hold down the mouse button to generate particles.
Move the mouse while holding the button to create different particle patterns.
Release the mouse button to stop generating new particles.
